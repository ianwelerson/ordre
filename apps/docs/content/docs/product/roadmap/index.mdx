## How to read this

- **[Launch](/internal-docs/product/roadmap/launch)** is a living map. Everything on it is in
  scope for the first release. It opens with the order the work is being done in
  and why that order was chosen, then lists the full scope by layer with a status
  against each piece. No dates or deadlines - the order is a sequence, not a
  schedule.
- **[Ideas](/internal-docs/product/roadmap/ideas)** is a backlog, not a plan. Nothing there is
  scheduled or designed. It's where possibilities get captured and explored;
  anything that graduates from an idea into committed work moves onto the Launch
  checklist (or a future release scope).
