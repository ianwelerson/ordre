Ordre is a client communication platform for service providers. It gives every
job a private, shareable status board that clients can follow in real time - no
app download, no account creation, just a link.

This is the internal documentation: how the product works, how the codebase is
organized, the infrastructure behind it, and how it is priced. The
[API Reference](/api-docs) is generated from the live OpenAPI spec.

## API Reference

The [API Reference](/api-docs) documents every endpoint of the Ordre REST API,
with an interactive playground for trying requests. It is generated from the
OpenAPI spec that `apps/api` produces, so it always matches the deployed
contract.

## The product in one minute

A workspace member creates a **board** for each job, picks a template for their
industry, and shares a unique link. The client opens it - no login - and sees a
live timeline of updates, photos, approvals, and chat. Sensitive fields stay
blurred until the client verifies their identity. Everything about the job lives
in one place.
