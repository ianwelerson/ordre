## Activity Feed (one table per type)

📋 **Planned** - no table in the schema yet. Seven feed tables plus `feed_approval_line_item`.

Each card in the board feed is its own table. They share a common shape -
`boardId`, an author, `createdAt`, and a `visibility` - then add their own fields.

**Shared columns** (on every feed table):

| Field            | Type                              | Notes                  |
| ---------------- | --------------------------------- | ---------------------- |
| `id`             | uuid                              |                        |
| `boardId`        | fk → board                        |                        |
| `authorType`     | enum `member \| client \| system` |                        |
| `authorMemberId` | fk → workspace_member, nullable   | Null for client/system |
| `visibility`     | enum `client \| team \| internal` |                        |
| `createdAt`      | timestamp                         |                        |

### `feed_update` - status update

| Field  | Type | Notes           |
| ------ | ---- | --------------- |
| `body` | text | The update text |

### `feed_internal_note` - team-only note

| Field  | Type | Notes                             |
| ------ | ---- | --------------------------------- |
| `body` | text | `visibility` is always `internal` |

### `feed_milestone`

| Field   | Type           | Notes          |
| ------- | -------------- | -------------- |
| `title` | text           | Milestone name |
| `body`  | text, nullable | What it means  |

### `feed_stage_transition`

| Field       | Type | Notes          |
| ----------- | ---- | -------------- |
| `fromPhase` | text | Previous phase |
| `toPhase`   | text | New phase      |

### `feed_system_event`

| Field  | Type | Notes                                              |
| ------ | ---- | -------------------------------------------------- |
| `text` | text | "Board created · Client link sent to M. Delacroix" |

> `authorType` is `system` for these rows.

### `feed_approval` - approval request

| Field                        | Type                                   | Notes                    |
| ---------------------------- | -------------------------------------- | ------------------------ |
| `description`                | text                                   | "Crown tube replacement" |
| `body`                       | text, nullable                         | Why it needs approval    |
| `amount`                     | decimal, nullable                      |                          |
| `currency`                   | text                                   | e.g. CHF                 |
| `status`                     | enum `pending \| approved \| declined` |                          |
| `respondedAt`                | timestamp, nullable                    |                          |
| `respondedByClientContactId` | fk → client_contact, nullable          |                          |

#### `feed_approval_line_item`

Multi-item cost breakdowns (optional).

| Field        | Type               | Notes |
| ------------ | ------------------ | ----- |
| `id`         | uuid               |       |
| `approvalId` | fk → feed_approval |       |
| `label`      | text               |       |
| `price`      | decimal            |       |
| `order`      | int                |       |

### `feed_visit_report` - recurring boards

| Field     | Type       | Notes                           |
| --------- | ---------- | ------------------------------- |
| `visitId` | fk → visit | The visit this report documents |
| `body`    | text       | What was done                   |

> Photos attach to any feed row via the shared **`media`** table below.

## Client Verification

📋 **Planned** - no table in the schema yet.

Identity verification is **session-based** - the entered email/phone is matched
and **not stored** (see [Specs](/internal-docs/product/specs)). The "verified" state lives
in the client's session, not the database. Optionally keep an audit log:

### `verification_attempt` (optional, audit only)

| Field         | Type                  | Notes                              |
| ------------- | --------------------- | ---------------------------------- |
| `id`          | uuid                  |                                    |
| `boardId`     | fk → board            |                                    |
| `matched`     | boolean               |                                    |
| `via`         | enum `email \| phone` |                                    |
| `attemptedAt` | timestamp             | Do **not** store the entered value |
