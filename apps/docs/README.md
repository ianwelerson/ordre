# docs

Ordre's documentation site, served at `docs.ordre.app`. Built with
[Fumadocs](https://fumadocs.dev) on Next.js. It hosts two sections:

- **Guides** (`/internal-docs`) - product, architecture, infrastructure, specs,
  pricing, brand, and roadmap.
- **API Reference** (`/api-docs`) - generated from the OpenAPI spec with
  [`fumadocs-openapi`](https://fumadocs.dev/docs/ui/openapi), including an
  interactive request playground.

The root (`/`) has no page of its own - it redirects to the Ordre marketing site
(`ordre.localhost` locally, `ordre-marketing.vercel.app` on preview, `ordre.app`
in production; see `marketingUrl()` in `src/lib/shared.ts`).

## Commands

Run from the repo root:

```bash
pnpm docs:dev      # dev server, proxied to https://docs.ordre.localhost via portless
pnpm docs:start    # serve the production build (run `pnpm build` first)
pnpm build         # production build (included in the monorepo build)
```

## Guides

Guide pages live in `content/docs` as MDX. Navigation order is defined in
`content/docs/meta.json`. Each page maps to a URL under `/internal-docs`:

| File                 | URL                             |
| -------------------- | ------------------------------- |
| `index.mdx`          | `/internal-docs`                |
| `architecture.mdx`   | `/internal-docs/architecture`   |
| `specs.mdx`          | `/internal-docs/specs`          |
| `infrastructure.mdx` | `/internal-docs/infrastructure` |
| `pricing.mdx`        | `/internal-docs/pricing`        |
| `brand.mdx`          | `/internal-docs/brand`          |
| `roadmap.mdx`        | `/internal-docs/roadmap`        |

## API Reference

The OpenAPI spec is generated from the route registrations in `apps/api`:

```bash
pnpm api:docs:generate   # writes apps/docs/public/openapi.json
```

`fumadocs-openapi` then turns that spec into MDX pages (one per operation) under
`content/api-docs`, rendered at `/api-docs`:

```bash
pnpm docs:openapi        # node scripts/generate-api-docs.mjs
```

`content/api-docs` is generated (gitignored) and rebuilt automatically on
`postinstall`, `build`, and `check-types`. `apps/docs/public/openapi.json` is
regenerated by lint-staged whenever files under `apps/api` change.

## Layout

| Path                           | Description                                       |
| ------------------------------ | ------------------------------------------------- |
| `src/app/page.tsx`             | Root redirect to the marketing site.              |
| `src/app/internal-docs`        | Guides layout and `[[...slug]]` pages.            |
| `src/app/api-docs`             | API reference layout, landing, and pages.         |
| `src/app/api/search/route.ts`  | Search route handler.                             |
| `src/proxy.ts`                 | Serves raw guide markdown (`/page.md`, `Accept`). |
| `src/lib/source.ts`            | `source` (guides) and `apiSource` (API) loaders.  |
| `src/lib/openapi.ts`           | `createOpenAPI` server instance.                  |
| `src/components/api-page.tsx`  | `APIPage` component for the generated MDX.        |
| `src/lib/layout.shared.tsx`    | Shared nav/layout options.                        |
| `scripts/generate-api-docs.ts` | Generates the API MDX from `public/openapi.json`. |
