# Design Tokens

The **@ordre/ui** Design Tokens are a fundamental part of modern design systems. They are a set of variables that store visual design values like colors, typography, spacing, and more. These values are used throughout the UI to ensure consistency across the design and code, making it easy to update and maintain a unified design system.

## Reset

The project uses a reset to ensure consistent styling across all browsers, devices, and operating systems. The reset used is from [Tailwind Preflight](https://unpkg.com/tailwindcss@3.4.17/src/css/preflight.css).
