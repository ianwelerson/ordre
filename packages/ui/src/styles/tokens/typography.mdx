# Typography

Typography tokens are defined as Tailwind v4 CSS variables in `./fonts.css`. Each group uses a Tailwind-native prefix, so utilities are generated automatically: families (`font-body`), sizes (`text-lg`), weights (`font-bold`), tracking (`tracking-tight`), and line-height (`leading-base`).

The scale is grouped into:

- **Family** - `font-headline`, `font-body`, `font-mono`.
- **Size** - `text-sm` → `text-4xl`.
- **Weight** - `font-light`, `font-normal`, `font-medium`, `font-semibold`, `font-bold`.
- **Letter spacing** - `tracking-tight`.
- **Line height** - `leading-xsmall`, `leading-small`, `leading-base`.

## Usage

```tsx
// Tailwind utilities
<h1 className="font-headline text-4xl font-bold tracking-tight">Headline</h1>
<p className="font-body text-base">Body copy.</p>
<code className="font-mono text-sm">inline()</code>

// Raw CSS variable
<h1 style={{ fontFamily: 'var(--font-headline)' }}>Headline</h1>
```

## Adding a new font token

1. Add the variable to the right group in `./fonts.css` using the matching Tailwind prefix:

   | Group          | Prefix            | Utility      |
   | -------------- | ----------------- | ------------ |
   | Family         | `--font-*`        | `font-*`     |
   | Size           | `--text-*`        | `text-*`     |
   | Weight         | `--font-weight-*` | `font-*`     |
   | Letter spacing | `--tracking-*`    | `tracking-*` |
   | Line height    | `--leading-*`     | `leading-*`  |

   ```css
   @theme static {
     --text-5xl: 96px;
   }
   ```

2. Add an entry to the relevant array above so it shows up in this page.
