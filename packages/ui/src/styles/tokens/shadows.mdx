# Shadows

Shadow tokens are defined as Tailwind v4 CSS variables in `./shadows.css`. Every variable is declared as `--shadow-*`, so Tailwind automatically generates a matching utility for each one (`shadow-raised`, `shadow-popover`, and so on).

Each token maps to an **intent**, not an elevation number - reach for the one that matches what you're building, so the shadow values can evolve without touching consumers.

## Usage

```tsx
// Tailwind utilities
<div className="shadow-raised" />
<div className="shadow-popover" />

// Raw CSS variable
<div style={{ boxShadow: 'var(--shadow-modal)' }} />
```

## Adding a new shadow

1. Add the variable under the `@theme static` block in `./shadows.css`:

   ```css
   @theme static {
     --shadow-sticky: 0 2px 8px rgba(26, 29, 38, 0.05);
   }
   ```

   Once declared, Tailwind v4 automatically generates the utility (`shadow-sticky`).

2. Add an entry to the array in the **Scale** section above so it shows up in this page.
