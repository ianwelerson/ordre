# Spacing

Spacing tokens are defined as Tailwind v4 CSS variables in `./spacing.css`. Every variable is declared as `--spacing-*`, so Tailwind automatically generates utilities across the full spacing-aware property set: `p-*`, `m-*`, `gap-*`, `space-x-*`, `w-*`, `h-*`, `inset-*`, …

The scale follows Tailwind's numeric convention where each step is 4px (step `1` = 4px, step `2` = 8px, and so on). Half steps land on the 2px midpoints (`0.5` = 2px, `2.5` = 10px), and exist only where a component genuinely needs them - reach for a whole step first. Reach for these tokens instead of hard-coded pixel values so the rhythm of the UI stays consistent.

Be generous. Landing sections breathe at `py-24`–`py-30` (96–120px) vertical. If a screen feels busy, remove something rather than adding another container.

## Usage

```tsx
// Tailwind utilities
<div className="p-3 gap-2" />
<section className="py-8 px-4" />

// Raw CSS variable
<div style={{ padding: 'var(--spacing-3)' }} />
```

## Adding a new spacing step

1. Add the variable under the `@theme static` block in `./spacing.css`:

   ```css
   @theme static {
     --spacing-24: 96px;
   }
   ```

   Once declared, Tailwind v4 automatically generates utilities (`p-24`, `m-24`, `gap-24`, …).

2. Add an entry to the array in the **Scale** section above so it shows up in this page.
