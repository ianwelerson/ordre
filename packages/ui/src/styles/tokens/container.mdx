# Containers

Container tokens are defined as Tailwind v4 CSS variables in `./container.css`. Every variable is declared as `--container-*`, which Tailwind uses for two things: fixed widths (`max-w-site`, `w-md`) and container queries (`@md:flex`).

Like breakpoints, this namespace is **not** reset with `--container-*: initial`. Tailwind's `3xs`→`7xl` scale stays available and ours is added alongside it.

## Usage

```tsx
// Centred page gutter
<div className="max-w-site mx-auto px-5 nav:px-7" />

// Fixed width from the scale
<aside className="w-xs" />

// Raw CSS variable
<div style={{ maxWidth: 'var(--container-site)' }} />
```

## Adding a new container

1. Add the variable under the `@theme static` block in `./container.css`:

   ```css
   @theme static {
     --container-board: 540px;
   }
   ```

   Tailwind generates `max-w-board`, `w-board` and the `@board:*` container-query variant automatically.

2. Add an entry to both tables above so it shows up in this page.
