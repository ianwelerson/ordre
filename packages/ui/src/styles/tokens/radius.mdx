# Radius

Radius tokens are defined as Tailwind v4 CSS variables in `./radius.css`. Every variable is declared as `--radius-*`, so Tailwind automatically generates utilities (`rounded-sm`, `rounded-md`, `rounded-full`, …).

## Usage

```tsx
// Tailwind utilities
<div className="rounded-md" />
<button className="rounded-full" />

// Raw CSS variable
<div style={{ borderRadius: 'var(--radius-lg)' }} />
```

## Adding a new radius

1. Add the variable under the `@theme static` block in `./radius.css`:

   ```css
   @theme static {
     --radius-xs: 2px;
   }
   ```

   Once declared, Tailwind v4 automatically generates utilities (`rounded-xs`).

2. Add an entry to the array in the **Scale** section above so it shows up in this page.
