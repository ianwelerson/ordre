# Motion

Motion tokens are defined as Tailwind v4 CSS variables in `./motion.css`.

Motion here is **restrained**. No bounces, no confetti, no spring physics - transitions exist to keep a change legible, not to draw attention to themselves. If an animation is doing something other than explaining what just changed, remove it.

The scale is grouped into:

- **Duration** - `duration-fast`, `duration-base`, `duration-slow`, `duration-deliberate`.
- **Easing** - `ease-standard`, `ease-decelerate`.

> **Naming gotcha:** Tailwind reads named durations from the `--transition-duration-*` namespace, **not** `--duration-*`. Declaring `--duration-fast` silently generates no utility. The easing namespace is `--ease-*` as you would expect.

## Usage

```tsx
// Tailwind utilities
<button className="transition-colors duration-base ease-standard" />
<div className="transition-all duration-slow ease-standard" />

// Raw CSS variable
<div style={{ transition: 'opacity var(--transition-duration-fast) var(--ease-standard)' }} />
```

Tailwind's own default transition is already `150ms` / `cubic-bezier(0.4, 0, 0.2, 1)`, which matches `duration-base` and `ease-standard`. A bare `transition-colors` is therefore on-token without any extra classes - reach for the utilities when you need `fast` or `slow`.

## Adding a new motion token

1. Add the variable under the `@theme static` block in `./motion.css` using the matching Tailwind namespace:

   | Group    | Namespace                 | Utility      |
   | -------- | ------------------------- | ------------ |
   | Duration | `--transition-duration-*` | `duration-*` |
   | Easing   | `--ease-*`                | `ease-*`     |

   ```css
   @theme static {
     --transition-duration-deliberate: 400ms;
   }
   ```
